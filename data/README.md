# Canonical experiment data

The files in this directory are the source of truth for the rebuilt experiment. Generated summaries must be reproducible from these files; no result may be typed into a paper table.

- `mutants.jsonl`: one generation and validator-independent verification record per attempted mutant.
- `validator_runs.csv`: one row per golden baseline or mutant validator/configuration run, keyed by artifact hash and carrying baseline-delta fields.
- `baseline_deltas.csv`: explicit mutant-to-golden comparison status; missing baselines and baseline-existing failures remain visible.
- `at_observations.csv`: assistive-technology observations, with coder and evidence fields.
- `at_selection.csv`: the nine illustrative exploratory AT cases and their expected observations.
- `verapdf_runs.csv`: generated by the automated veraPDF batch after installation.
- `corpus_inventory.csv`: golden-PDF license, hash, page count, structural coverage, and resolved local filename mapping.
- `corpus_provenance_sources.csv`: suite-item titles, descriptive attribution, reproducible public source URLs, mapping basis, and provenance limitations for the nine local golden PDFs.
- `controls.csv`: negative/equivalent and positive machine-checkable harness controls.

The legacy files `pdfa11ymut_metrics_summary.json` and `pdfa11ymut_detection_analysis_data.json` are retained under the historical-data notice above; their 23-mutant values are not current inputs. `release_manifest.json` is also a historical release record and must not be used as the current freeze identifier; use `STUDY_MANIFEST.json` instead.

Current canonical status: nine corpus inventory records, 73 valid verified generation records, 69 active mutants after all documented exclusions, and 207 classified formal validator rows across PAC Formal, Acrobat Full Check, and veraPDF. The generation ledger contains 71 materialized mutant PDFs, including the auxiliary AT artifact; the five excluded records remain visible in the canonical ledgers. `pac_ai_classifications.csv` contains all 34 selected mutant rows; every row is artifact-backed and explicitly retained as `AI_AMBIGUOUS`/`REVIEW_REQUIRED` because PAC does not provide the required supported complete semantic export/API. No PAC-AI detection or non-detection is inferred. `at_observations.csv` contains nine completed qualitative NVDA observations from an illustrative exploratory sample; the preserved transcripts and raw log are primary evidence, with screenshots available for only two cases. A missing run is `TODO`, not a pass, miss, or invented result.

The public clone deliberately excludes raw proprietary validator and assistive-technology evidence. Public scripts can rebuild the canonical analysis, manifests, summaries, and release boundary, but they cannot recollect PAC, Acrobat, or NVDA observations without the named native applications and private evidence. Hashes, classifications, and sanitized metadata remain public; excluded bytes are not claimed to be redistributable.
