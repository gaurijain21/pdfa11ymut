# Evidence layout

- `verification/`: per-mutant structural and rendering verification JSON.
- `pac/formal/`: PAC traditional/formal reports or screenshots.
- `pac/ai/`: PAC AI-assisted reports or screenshots.
- `acrobat/`: Acrobat Accessibility Checker reports/screenshots.
- `verapdf/`: veraPDF reports.
- `at/nvda/`: representative assistive-technology observations.

Every evidence file must be linked to the exact tested SHA-256 and tool version/settings. Do not place private conversation exports here as provenance.
