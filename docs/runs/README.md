# Run packets

The subbatch markdown files in this directory are retained operator run packets and historical execution plans. They are not the canonical completion ledger and may contain the original `TODO` queue state.

For current evidence status, use `data/validator_runs.csv`, `data/at_observations.csv`, `data/release_manifest.json`, and `scripts/check_evidence.py`. The current canonical release has 207 classified formal rows across 69 active mutants and nine completed qualitative NVDA pilot observations.
