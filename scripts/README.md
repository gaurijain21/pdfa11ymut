# Scripts

This folder contains scripts used during analysis and paper preparation.

## Files

- `build_detection_analysis.py` - builds the detection matrix and metrics from project inputs.
- `build_detection_workbook.mjs` - creates the editable Excel workbook.
- `build_paper_figures.py` - creates the original SVG paper figures.
- `build_ieee_assets.py` - creates PNG figure assets for the IEEE manuscript.

These scripts were copied from the working research workspace. Some paths may need adjustment if you want to rerun them from this GitHub release layout after adding the full source inputs, golden PDFs, mutants, and raw validator evidence.
