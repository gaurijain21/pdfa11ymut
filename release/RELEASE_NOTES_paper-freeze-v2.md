# PDFa11yMut `paper-freeze-v2`

This release preparation records the final submission-freeze boundary for the controlled PDF accessibility mutation-testing study.

The canonical artifact contains 9 reference PDFs, 10 operators, 73 valid verified generation records, 5 documented exclusions (4 within the valid-generation manifest and 1 historical exclusion-only record), 69 active mutants, 30 Class-A conformance-oriented mutants, 39 Class-B semantic/assistive-representation mutants, 207 active checker rows, 18 paired controls, and 9 exploratory AT cases.

The public artifact exposes source code, operator specifications, canonical classifications, sanitized evidence metadata, checksums, generated analyses, and reproducibility instructions. Raw PAC, Acrobat, veraPDF, NVDA, and Speech Viewer evidence bytes remain excluded from public redistribution unless separately cleared. Recollection of those records requires authorized native applications and the stated configurations.

The immutable Git tag is created only after the final clean commit, manifest, manuscript source/PDF hashes, tests, generated-analysis check, and submission audit pass. No DOI is claimed here; Zenodo DOI assignment remains an external release step.
