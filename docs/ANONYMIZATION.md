# Double-blind anonymization checklist

The canonical public repository is attributed to Gauri Jain and is not anonymized by default. Before submitting to a double-blind venue, prepare a separate submission copy and check:

- manuscript author names, affiliations, email addresses, acknowledgments, and self-identifying prose;
- repository URLs, commit links, release links, and artifact citations;
- PDF metadata including title, author, creator, and embedded source identifiers;
- filenames, directory names, figure captions, and supplementary-artifact references that identify the authors;
- acknowledgments, funding statements, institutional paths, and comments in source files.

Do not anonymize or rewrite the canonical public repository unless the venue explicitly requires it. Do not submit the named `paper-freeze-v2` artifact to a double-blind venue without preparing and separately reviewing the anonymized copy.
